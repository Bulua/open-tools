# PDF 内容编辑

「PDF 内容编辑」的页面、逻辑、Worker 和测试统一放在 `src/tools/document/pdf-content-editor/`，工具定义与三语言文案分别在同目录的 `index.ts`、`locales.ts`，PDF 读取与渲染复用 `document/shared/`。支持替换可定位的横排原文，以及叠加文字、图片、手写签名、高亮和图形。`pdfEditor.ts` 保存以 PDF.js 可见页面为基准的坐标，导出时先生成透明叠加页，再根据旋转和 CropBox 转换回原页坐标，保留原文件的文字、图片与矢量内容。新增文字使用 `@pdf-lib/fontkit` 嵌入字形子集，仍可搜索；其他新增对象写入页面内容，导出后不保留编辑器的独立对象状态。手写签名是图形，不是数字证书签名。

## 文件与职责

编辑器按职责组织：`PdfEditor.vue` 协调编辑流程与交互；`pdfEditorModel.ts` 定义编辑数据、快照、撤销重做及共用几何；`pdfEditor.ts` 专注 PDF 导出；`usePdfEditorFonts.ts` 负责字体匹配、注册和释放；`usePdfPagePreview.ts` 负责页面位图、解码切换、缩略图队列与 URL 回收。异步任务在文档切换后须丢弃旧结果，字体测宽与导出共用 `PDF_TEXT_FEATURES`。

## 字体与导出

通过 `src-tauri/src/tools/document/pdf_content_editor/` 枚举系统已安装的轮廓字体（包括当前用户安装的字体），读取 name 表中的中英文及 PostScript 别名，按原文名称、粗体和斜体匹配。本机同款完整字体优先于 PDF 内嵌子集，字体下拉框也支持搜索并手动选择本机字体。列表在进程内缓存，字体内容按需读取；不接受前端提供文件路径。通过 GDI 按表读取并重建独立 sfnt，支持 TTC 集合中的字体，WebView2 预览与导出共用同一份字节。读取时检查嵌入权限；不允许可编辑子集嵌入的字体会拒绝加载。未找到可用原字体时明确提示使用替代字体；输入缺字时保留当前选择并提示，导出会拒绝缺字，不自动整行切换字体。安装新字体后需重启应用刷新列表。

内置的 Noto Sans CJK 字体位于 `src/assets/fonts/`，随应用打包，支持中英日，无需联网载入。原始字体约 16 MB，来源和授权见同目录 README；授权副本还放在 `public/licenses/`，确保打包时随字体分发。编辑器也支持导入本机 TTF / OTF。导出前检查字体缺字和文本框溢出，不能静默截断文字。

## 原文定位与替换

原文定位与移除由 `pdfTextEngine.ts` 使用 MuPDF 在模块 Worker 中完成，WASM 随程序打包，不访问远程服务。旧文字先在副本中真实移除，再由 `pdfEditor.ts` 写入替换内容；移除前后比较剩余字符及其位置，不满足条件时拒绝导出。图片、底色和线条不参与删改。原文保留字体名、首行基线、行距、文字原点、字距和水平缩放；字号与水平缩放从 MuPDF 绘制设备的实际文字矩阵分别读取，不使用结构化文字中随水平压缩变化的面积字号。字形 advance 使用绘制时的 glyph ID，不能用 Unicode 反查 CID 子集字体的 glyph ID。输入框和导出使用相同的字距、缩放及原点偏移，并关闭浏览器的可选字偶距和连字，测宽按实际导出字体的 glyph advance 计算；优先匹配本机同款字体，其次提取 PDF 中可直接加载的 TrueType/OpenType 字体，子集缺字或原文字体无法复用时提示改用替代字体，不自动重排周围段落。

点击原文只创建临时输入框，未实际修改时不移除或重画原文，也不生成撤销记录。扫描件的隐藏 OCR 文字层、竖排和旋转文字暂不支持直接编辑。打开文件和翻页时自动读取当前页，按同一文本块内相同字体的相邻行生成原文编辑框，输入时即时显示替换内容。MuPDF 授权随应用放在 `public/licenses/MuPDF-AGPL.txt`，ES 模块 Worker 需要 ES2022 的顶层 await 支持；开发模式通过 `optimizeDeps.exclude` 排除 MuPDF 的旧目标预打包，以免动态导入失败。

## 编辑交互

编辑区域使用连续页面布局，滚动同步当前页和缩略图的加粗强调色边框，并将当前缩略图保持在侧栏可视范围内，边框加粗时同步扣减内边距以保持尺寸稳定；屏幕附近的页面按需渲染并释放远处位图；缩放期间保留旧位图。右侧不显示对象属性；顶部为统一的两层工具栏，上层按文字编辑、素材与标注分组，撤销、缩放及导出靠右，下层只显示当前工具或选中对象适用的属性。字体标签不折行，不透明度显示百分比；顶部不显示说明、原文字体、加载状态或即时校验提示行，避免输入与选中时改变页面纵向位置；读取、处理和导出错误继续通过统一错误提示处理。工具选中高亮复用 `utils/motion.ts`，属性区通过裁剪和轻微位移展开，不做内容淡入淡出或文字缩放，并遵循系统减少动态效果设置。

编辑器中的文字直接在页面上输入，默认不自动折行，只有显式回车换行；输入时根据字体度量向页面右侧扩宽文本框；粘贴和输入法组合期间根据输入框实际值同步扩宽 DOM 并在 Vue 更新后清除内部滚动，输入框内不显示滚动条。超出页边的内容仍保持单行编辑，并提示溢出、在导出时拒绝越界内容。界面显示与 PDF 导出使用相同的显式换行，不能在导出阶段再次按框宽拆行。双击新增文字可以继续编辑；输入失焦后作为一次操作记录，空白新增输入不生成对象。新增文字的按下事件必须阻止默认焦点转移，避免浏览器在输入框聚焦后触发失焦；文字工具保持启用，便于连续添加。文字容器空白处不拦截点击，选中的文字框通过上方独立手柄移动，避免移动与输入冲突。未改字的原文也可直接通过手柄移动或缩放；开始手势时失焦处理须保留临时对象，无实际移动或取消时不生成替换和撤销记录。

原文移除与重绘期间保留旧页面位图，不显示整页遮罩；新位图解码后一起切换背景与替换文字层，避免闪白和叠字，之后再释放旧 URL。左侧栏支持拖动分隔条调整宽度，也可用方向键调整。签名模式不显示笔迹的选中框，切换选择模式后仍可调整笔迹。Ctrl + 滚轮以鼠标附近为中心缩放，异步重绘期间保留上一次页面图像。左侧读取 PDF 自带书签（含层级、命名目标及页对象目标），仅在确实存在目录时显示目录切换；导出时保留原书签。

箭头头部默认 24 pt，可在工具栏调整为 4～96 pt，独立于线宽保存，支持撤销重做。预览和导出复用同一套头部坐标；SVG 允许绘制超出线段包围框的两翼与圆头线帽，不能按对象视口裁切箭头。

## 验证

新增编辑逻辑需要覆盖旋转、裁切页面的坐标测试，及中英日文字、图片、图形、撤销重做的回归测试。界面效果仍由用户自行检查，不使用浏览器截图验收。


## 工具 ID 与迁移

PDF 内容编辑与 PDF 页面管理的工具 ID、目录分别为 `pdf-content-editor`、`pdf-page-manager`；历史 ID 通过 `src/tools/toolId.ts` 映射，保留收藏、最近使用和分类选择。页面管理支持点击独立选中或取消单页，Shift 追加连续范围，复选框与页面点击保持一致。
