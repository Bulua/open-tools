# MQTT 连接

位置为「网络 → MQTT 连接」。前端位于 [mqtt-client](../../src/tools/network/mqtt-client)，Rust 连接、订阅和发布逻辑位于 [mqtt_client](../../src-tauri/src/tools/network/mqtt_client)。

## 连接与协议

MQTT 连接支持独立会话，每个会话可选择 MQTT 3.1.1 或 5.0，已有配置默认使用 3.1.1。两个 MQTT 版本均通过 Rust `rumqttc` 支持 `mqtt://`（TCP）、`mqtts://`（TLS）、`ws://`（WebSocket）和 `wss://`（TLS WebSocket）。服务器地址由协议下拉框、域名/IP 与独立端口组成，WebSocket 额外配置 Path（默认 `/mqtt`，允许查询参数）。

默认端口分别为 1883、8883、80、443；切换协议只调整仍为原协议默认值的端口，保留自定义端口。旧配置按 `tls` 字段迁移为 `mqtt` 或 `mqtts`。TLS 与 WSS 均使用系统可信证书并校验服务器名称。

连接超时默认 10 秒，协议确认超时为 15 秒，可在新建会话的高级配置中开启自动重连。订阅等待 SUBACK，取消订阅等待 UNSUBACK，QoS 1/2 发布分别等待 PUBACK/PUBCOMP；QoS 0 不保证服务器收到。

## 收发格式与限制

每条发送内容最多 256 KiB，记录同时受最近 200 条和 4 MiB 原始载荷限制；发送区和消息列表均支持 Plaintext、Base64、JSON 和 Hex。Plaintext 与 JSON 按原文发送 UTF-8 字节，Base64 与 Hex 忽略空白后解码为字节发送，输入非法时禁用发送并提示；256 KiB 上限按实际发送字节计算。发送格式切换只改变输入的解释方式，不改写草稿。

收发记录保留原始字节，发送记录保存发送时的格式与输入原文，后续切换发送或接收格式都不会改写已有发送记录；列表顶部的「接收格式」只作用于接收消息，发送区单独标为「发送格式」。Base64 与 Hex 可无损查看二进制，Plaintext 按 UTF-8 显示，JSON 尝试格式化，非 JSON 保留文本；非 UTF-8 消息显示二进制标记。

## 工作区与订阅筛选

右侧默认采用单页布局：顶部连接参数采用两行网格，MQTT 版本位于第二行，清除会话位于第二行最右侧，窄窗口自动调整列数。状态左侧的编辑按钮在断开连接时可用，复用添加连接的常规、高级和遗嘱配置页，保存更新当前连接，取消丢弃修改；下方订阅区与消息区通过可拖拽分隔线调宽。新增订阅通过订阅栏标题右侧的「＋ 订阅」按钮打开弹框。

消息区以收发消息气泡显示主题、QoS、正文、时间、字节数与格式，不再提供点击展开的详情面板。消息正文支持直接选中文字复制，鼠标按下或键盘聚焦消息时暂停自动滚动，新消息不打断阅读；可勾选「自动滚动」恢复跟随。发送区常驻底部，发送按钮位于消息输入框内右下角。

发送主题采用较短的可输入下拉框，候选来自当前连接的预设订阅和现有发送记录，去重并排除含通配符的主题，支持输入筛选、方向键选择及直接输入新主题；切换连接关闭菜单且不混用候选。顶部输入框限制为合适宽度，发送参数选择器使用深层选择器限定公共 AppSelect 的宽度。点击订阅主题可按 MQTT 主题过滤器筛选当前会话已有的收发记录，支持 +、# 与系统主题匹配规则；点击「全部订阅」恢复完整列表，筛选不会删除消息或拉取服务器历史，页面本身不纵向滚动；消息、订阅列表及编辑器在各自区域内滚动。

## 会话目录与持久化

左侧为文件夹与会话目录，顶部仅保留新建文件夹和会话按钮；项目右键菜单仅提供重命名和删除，移动与排序只通过拖拽完成，空白处右键菜单在根目录新建。目录支持折叠和拖拽排序，与右侧工作区共用外框；分隔线可拖拽或用方向键调宽，记住宽度，双击恢复默认。目录结构及每个会话的连接参数、预设订阅与发送草稿自动保存至统一数据库 `open-tools.db`，旧的命名配置和未保存草稿迁入目录。

右侧显示选中会话的独立单页工作区，不再使用工具公共标签栏。密码和收发消息记录不持久化。重新打开时不自动连接，用户手动连接成功后恢复预设订阅，活动状态以服务器确认结果为准。

切换会话保留连接和消息，删除会话或包含它的文件夹时释放连接；删除非空文件夹先确认。取消「清除会话」时，服务器可能恢复此客户端 ID 以前的订阅；工具无法枚举服务器保存的订阅列表。
