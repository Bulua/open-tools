# 时钟

位于「时间」分类。一个面板顶部切换「闹钟 / 秒表 / 计时器」，切换使用公共分段选择控件的滑动效果。

- 闹钟：最后一张卡片用于新增，弹窗内设置时间、多选每周重复日及标签；不选星期表示只提醒一次。已有闹钟可编辑、启停和删除。
- 秒表：左侧显示时分秒和百分之一秒，运行时可分段，暂停时可复位。右侧记录每段耗时，悬停时间可查看累计用时。暂停不累计时间，切换工具后仍继续当前计时，完全退出程序后清空。
- 计时器：暂时只有空面板，等待后续设计。

闹钟在程序运行时检查，到期显示全局提醒并播放提示音，Windows 桌面版同时通过与日历相同的系统通知显示闹钟时间和标签；关闭程序期间到期的提醒在下次启动时补发一次。重复闹钟随后排到下一次选中时刻。桌面通知失败不会中断应用内提醒或重复排期。

前端代码在 `src/tools/utility/clock/`，原生读写在 `src-tauri/src/tools/utility/clock/`。继续读取原来的 `countdowns.json`、浏览器 `countdowns` 存储和原生命令，以兼容已有提醒。旧版提醒保留显示和删除入口；收藏、最近使用、分类选择自动从旧工具 ID 迁移到 `clock`。
