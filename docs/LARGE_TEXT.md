# 大文本编辑器（第一版）

桌面端「文档 / 文件」分类中的「大文本编辑器」，也可通过工具搜索找到。开发时运行 `npm run tauri dev`，打开本机文本文件或将文件拖入工具。支持一次选择或拖入多个文件，最多八个标签；重复打开同一文件会切回已有标签。

## 界面布局

初始仅显示可点击或拖入文件的面板，打开后标签栏与编辑区域组成一个整体；标签栏加号可继续打开文件。编辑工具栏集中保存、撤销 / 重做、查找、跳转与分块导航；查找和行号输入默认收起，可点击按钮或按 `Ctrl+F` / `Ctrl+G` 展开，按 Esc 收起。底部状态栏显示保存状态、文件路径、行列位置、文件大小、行数、换行格式和编码。编码可直接在底部切换，使用说明通过悬停查看；文件路径隐藏 Windows 扩展路径前缀。

## 使用方式

- 每次按约 256 KiB 读取；滚动到底部或顶部后继续滚动，会自动接入相邻内容。页面只保留附近三块，移除较远内容前先暂存修改，向回滚动时重新读取。仍可用「上一块 / 下一块 / 开头 / 末尾」直接导航；超长行可能分段显示。
- 支持按行跳转、区分大小写的普通文本查找。查找下一个到达末尾后，可选择从头查找。
- 当前块可以直接编辑；切块、查找、跳转时会先暂存修改，不会立刻写回原文件。
- 点击「保存原文件」或按 `Ctrl+S`，将整个修改后的文档流式写回原路径。
- 支持当前块撤销 / 重做，以及最近 100 次跨块修改记录。保存后仍可撤销；需要再次保存才会改变磁盘文件。
- 点击标签右侧菜单按钮，或右键标签，可以关闭当前、左侧、右侧标签。左右以打开菜单的标签为基准，不包含该标签；未保存修改逐个提示，中途取消则保留本次准备关闭的全部标签。
- 每个文件标签独立保存编码、查看窗口、滚动位置、选区、撤销 / 重做历史、查找词、跳转行号、草稿及任务状态。新文件默认自动识别编码，不继承其他标签的编码。
- 切换标签或其他工具后仍保留文件和草稿。关闭标签只处理该文件；退出程序或安装更新前逐个提示未保存文件，全部确认后才关闭。中途取消会保留所有标签。

## 编码与原文件保护

打开时支持自动识别、UTF-8、UTF-16 LE / BE、GBK。自动识别优先使用 BOM，其次严格验证 UTF-8，最后尝试 GBK；无 BOM 的 UTF-16 等有歧义内容需要手动指定。打开后切换编码会自动重新读取当前文件，并回到文件开头；有未保存修改时先提示保存、放弃或取消。取消或新编码解码失败时保留原会话及编码选项，不需要重新选择文件。此操作是重新解释文件字节，第一版不提供转码保存。

未修改片段保留原始字节，包括 BOM 和混合换行；新增换行采用打开时从文件开头采样得到的换行方式。不支持的字符编码会拒绝写入，不会用问号替代。

保存先在原目录写入临时文件，完成并刷盘后再替换原路径，不生成 `.bak` 备份。成功后不保留临时文件；替换失败时保留写好的临时文件并报告恢复位置。已有的备份文件不会自动删除。

保存需要原目录写权限和临时磁盘空间。读取期间会检查原文件身份、长度和修改时间，发现外部更改时拒绝覆盖。Windows 会话还会阻止其他程序同时写入，因此第一版不适合查看仍在持续写入的活动日志。只读文件仅允许查看、查找、跳转。

## 实现位置

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 前端 | `src/tools/document/large-text/` | Vue 页面、CodeMirror 编辑块、会话控制、多语言与测试 |
| Rust | `src-tauri/src/tools/document/large_text/` | 磁盘片段表、编码、稀疏行索引、后台任务与安全保存 |

前端每个标签只持有附近的文本块；编辑窗口最多 1 Mi 个 UTF-16 代码单元。Rust 用文件片段表引用原内容，新增内容写入应用数据目录 `large-text` 的临时编辑文件，关闭会话时清理。后台索引每个读取块保存一个行号检查点，不将全文或所有行装入内存。

## 第一版边界与验证

选择、复制仅限当前已加载窗口；非空选区不阻断边界加载，读取后恢复视口和选区。连续滚轮距离会合并处理，只有越过当前窗口时继续串行读取相邻块。不包含全文选择复制、正则搜索、全局替换、自动换行、实时追踪日志、崩溃恢复。草稿保护仅覆盖当前正常运行的会话，意外断电或强制终止后不能恢复未保存修改。

仓库包含前端交互测试和 Rust 小文件回归测试，覆盖编码、字符边界、混合换行、多处编辑、撤销、取消保存、原路径保存及外部更改保护。大文件性能和 Windows 桌面交互由实际使用环境验证；Linux 下的独立引擎测试与 Windows 目标编译检查不能替代 Windows 整个应用的运行测试。
