# PDF 内容编辑器字体

`NotoSansCJKsc-Regular.otf` 来自 Noto CJK 项目的简体中文常规字体，同时包含日文假名及拉丁字符。

- 来源：https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
- 随附原始授权文件：`OFL.txt`（SIL Open Font License 1.1）。字体文件未经修改。
- 字体随程序打包，编辑 PDF 时不访问网络。导出时仅嵌入文档实际使用的字形子集。
- 如需其他字体，可以在编辑器中导入本机的 TTF / OTF 文件；导入的字体只保存在当前会话。
